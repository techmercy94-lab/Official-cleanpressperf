💎 AFFILIATE PROGRAM FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SIGNUP PHASE:
  1. Affiliate joins: /affiliate → "Join Affiliate Program"
  2. Gets unique code: AFF_ABC123
  3. Generates referral link: https://site.com/auth/sign-up?ref=AFF_ABC123

REFERRAL PHASE:
  1. Affiliate shares referral link
  2. New customer clicks link & signs up
  3. System validates affiliate code
  4. Creates PERMANENT record: affiliate_customers(affiliate_id, customer_id)

PURCHASE PHASE:
  1. Customer places order: ₦5,000 perfume + free delivery
  2. Payment processed via Stripe
  3. Webhook: updateOrderStatus('paid') called

COMMISSION PHASE:
  1. System detects: status='paid' + has affiliate_id
  2. Calculates commission: ₦5,000 × 15% = ₦750
  3. Creates commission record (status='pending')
  4. Affiliate sees on /affiliate/dashboard

APPROVAL PHASE:
  1. Admin visits /admin/commissions
  2. Reviews commission
  3. Clicks "Approve"
  4. Status changes: pending → approved

WITHDRAWAL PHASE:
  1. Affiliate goes to /affiliate/withdraw
  2. Enters bank details & amount
  3. Creates withdrawal request
  4. Admin visits /admin/withdrawals
  5. Approves withdrawal
  6. Status changes: pending → paid

LIFETIME TRACKING:
  1. Same customer makes 2nd purchase
  2. ALL commissions link to ORIGINAL affiliate
  3. Commissions accumulate indefinitely
